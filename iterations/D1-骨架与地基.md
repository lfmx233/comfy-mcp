## 关键决定

1. **`status()` 永不抛异常。** 连不上时返回 `reachable=false + error`，让 Agent 拿到可读原因，而不是一个 MCP tool error。代价是调用方要自己看 `code` 字段。
2. **显存统一换算成 GB。** ComfyUI 返回字节数（8585216000），模型对数字量级不敏感，换成 `8.0` 和 `6.94` 才能判断「够不够跑 SDXL」。
3. **假 ComfyUI 做成有状态。** `/prompt` 会真的写一条 history，`/view` 返回真 PNG（1×1）。这样 D3 的 run → 取图链路不用重做假服务器。
4. **不引 pydantic 定义返回结构。** 直接 dict + `code` 字段，MCP SDK 自动生成 outputSchema；少一层模型同步成本。代价是字段拼错要在测试里兜住。
5. **加 `--check` CLI 而不是只留 MCP 入口。** 面试 demo 时不用先配 Claude Desktop，一条命令能证明「真连通了」。

## 踩坑

### 1. pip 直连 PyPI 慢到不可用

`https://pypi.org/simple/` 页面 48MB，10 秒只拉到 0.6MB（`curl: (28) Operation timed out`）。
→ 全程改用 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。

### 2. PowerShell 管道接原生命令会挂死

`& python -m pip install ... | Select-Object -Last 25` 一挂就是几分钟不出字。
→ 改成「后台 job + 独立日志文件 + 读文件」。教训：**日志文件名每次换新**，否则被残留 pip 进程锁住：

```text
out-file : 文件"...\.pip.log"正由另一进程使用，因此该进程无法访问此文件。
FullyQualifiedErrorId : FileOpenFailure,Microsoft.PowerShell.Commands.OutFileCommand
```

排查方式：`Get-CimInstance Win32_Process -Filter "Name='python.exe'"` 看命令行，杀掉废弃的 pip。

### 3. MCP SDK 2.x 的 HTTP 客户端叫 `httpx2`

`import httpx` → `ModuleNotFoundError: No module named 'httpx'`。
SDK 2.3.0 依赖的是 `httpx2 2.16.2`（API 与 httpx 一致，import 名就是 `httpx2`）。`pyproject.toml` 里同步写 `httpx2>=2.10.0`。

### 4. pytest 找不到 `tests.fake_comfy`

src 布局下必须显式：

```toml
[tool.pytest.ini_options]
pythonpath = ["src", "."]
```

### 5. 结构化结果字段名是 `structured_content`

服务端返回的 `CallToolResult.model_dump()` 里是 snake_case：`structured_content`（协议层是 `structuredContent`）。冒烟脚本最初只读驼峰，结果 `SMOKE: FAIL` 而数据其实是对的。

### 6. 中文路径 + `pip install -e` 会让整个解释器起不来

editable 安装写出的 `_editable_impl_comfy_mcp.pth` 内容是 UTF-8 的 `D:\工作\...\src`，CPython 的 `site` 模块按 GBK 读：

```text
Fatal Python error: init_import_site: Failed to import the site module
UnicodeDecodeError: 'gbk' codec can't decode byte 0xaa in position 12: illegal multibyte sequence
```

此时连 `python -c "print(1)"` 都失败。`PYTHONUTF8=1` 无效。
→ 删掉该 `.pth`，改用非 editable 安装 `pip install .`；日常开发用 `pytest`（走 pythonpath）与 `set PYTHONPATH=src`。

### 7. pip 缓存目录拒绝访问

```text
WARNING: Building wheel for comfy-mcp failed: [WinError 5] 拒绝访问: 'c:\users\lfmx\appdata\local\pip\cache\wheels\3a'
```

→ `--no-cache-dir`。

### 8. 真机 ComfyUI 的无关噪音

启动日志里 ComfyUI-Manager 报 `aiohttp ClientConnectorError: Cannot connect to host raw.githubusercontent.com:443`，只影响它自己的缓存拉取，`/system_stats` `/prompt` 都正常。真机数据：v0.3.60 / python 3.12.10 / torch 2.8.0+cu129 / RTX 4060 Laptop 8GB。
